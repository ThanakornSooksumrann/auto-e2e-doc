# auto-e2e-doc

Universal E2E Document Generation Skill for AI Agents (Gemini, Claude, Cursor, Codex).
Generate human-readable UI test flow documentation from Cypress tests, BRDs, or Redmine issues!

## Installation

```bash
git clone https://github.com/ThanakornSooksumrann/auto-e2e-doc.git
cd auto-e2e-doc
npm install
node scripts/setup.js
```
The setup wizard will ask for your environment URLs, credentials, and UI source path, and then automatically install the skill into your AI platform.
